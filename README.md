# Street Rush

Android skate runner by shambik. Download the latest APK from [Releases](https://github.com/shambik/street-rush-releases/releases/latest).

Current: **0.1.0.1** — consistent rider grab sprites, per-pose outfit colors, harder movement-based boss patterns and timed swipe counters.

Install over your existing app to keep progress. The app checks this repository for updates; Android asks you to approve installation. Versions use major.minor.hotfix.build. Source code is maintained separately in a private repository.

Phone movement/visual/performance review remains pending. Existing audio is retained.
