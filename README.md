# Street Rush

Android skate runner. Download the APK from [the latest release](https://github.com/shambik/street-rush-releases/releases/latest).

Versions follow **major.minor.hotfix.build**, starting **0.1.0.0**. Android 8 or newer is required.

This repository contains app downloads and release notes. The source is maintained in a separate private repository.

The app checks for releases automatically once a day. You can also tap the update row in its menu. Updates download inside the app; Android requires approval to install. Keep the existing app installed to preserve coins, unlocks and records.

Initial review release includes illustrated distance outfits, visible transformations and three moving bosses with dodge-to-counter skateboard contact attacks. Phone performance and gameplay balance remain in review.

The ElevenLabs audio replacement is pending a valid API key; this release retains the previous audio.
